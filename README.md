# 🚀 Taller Práctico: Directorio de Aprendices SENA con Git & GitHub

Bienvenido al repositorio oficial del **Taller de Control de Versiones con Git y GitHub**. Este proyecto fue diseñado especialmente para que los aprendices SENA dominen los fundamentos del trabajo con Git, la colaboración en equipo y la publicación de proyectos en sus propios repositorios de GitHub.

![Banner SENA](assets/avatares/avatar_instructor.svg)

---

## 🎯 Objetivo del Taller

Al finalizar este taller, serás capaz de:
1. **Configurar tu entorno local de Git** con tu nombre y correo institucional.
2. **Clonar repositorios** y navegar por su estructura de archivos.
3. **Crear y gestionar ramas de trabajo** (`feature branches`) para no alterar la rama principal directamente.
4. **Registrar cambios atómicos** con buenas prácticas de mensajes de commit (`Conventional Commits`).
5. **Vincular y subir tu proyecto a un repositorio personal en GitHub**.
6. **Publicar tu portafolio web en vivo** mediante **GitHub Pages**.

---

## 🚦 Inicio Rápido (3 Pasos)

1. **Lee las instrucciones detalladas:**  
   Abre el archivo [INSTRUCCIONES.md](INSTRUCCIONES.md) para seguir el paso a paso guiado desde tu terminal.
2. **Prueba la aplicación localmente:**  
   Haz doble clic sobre el archivo `index.html` o ábrelo con una extensión como *Live Server* en VS Code.
3. **Consulta los comandos si tienes dudas:**  
   Revisa la [GUIA_COMANDOS_GIT.md](GUIA_COMANDOS_GIT.md) para recordar la sintaxis de `clone`, `branch`, `checkout`, `add`, `commit` y `push`.

---

## 👥 Criterios de Entrega

Para dar por superado el taller, debes entregar al instructor el **enlace a tu repositorio personal en GitHub** y la **URL pública de GitHub Pages**, cumpliendo con la [LISTA_CHEQUEO_EVALUACION.md](LISTA_CHEQUEO_EVALUACION.md).
